# Studio Video Affiliate

Aplikasi web (PWA) untuk membuat video affiliate dengan Google Flow:

1. **Rencana & Prompt**: isi info produk, pilih durasi (8–40 detik), lalu dapatkan prompt Flow per klip, narasi, hook, dan caption.
2. **Generate di Flow**: panduan memakai kredit gratis Google Flow.
3. **Rakit Video**: gabungkan klip hasil Flow, tambahkan teks, subtitle, penutup, dan label "Visual dibuat dengan AI", lalu simpan sebagai video.

Semua proses berjalan di browser; tidak ada data yang dikirim ke server.

Install di HP: buka link GitHub Pages-nya → menu browser → "Tambahkan ke layar utama".
